# Good Food

Food delivery web app with cart and order tracking.

## Features

- Categories and cart
- Order confirmation and tracking map
- Dockerised

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Leaflet
- MapLibre
- Docker

## Getting Started

```bash
git clone https://github.com/ghostland-dev/good-food-delivery.git
cd good-food-delivery
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
